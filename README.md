# 🤖 hh-tag-parser-console

### Консольная версия приложения для автоматического парсинга тегов на hh.ru по вакансиям


### [Версия с интерфейсом](https://github.com/mlpoffff/hh-tag-parser-app)


## ⚠️ Важная информация ⚠️
### Для работы приложению обязательно нужен установленный [node.js](https://nodejs.org/en/download).


## 🛠️ Инструкция по установке и запуску
1. Скачать и распаковать архив https://github.com/mlpoffff/hh-tag-parser-console/archive/refs/heads/main.zip
2. Команды:
* `npm install` - установка зависимостей
* `node app.js "PHP developer" 5` - запуск парсинга тегов. В кавычках пишется название вакансии, цифра означает кол-во страниц для парсинга(опционально). Результат будет выведен в консоль и сохранен в excel файл
